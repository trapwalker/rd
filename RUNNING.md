## Быстрый старт

### 1. Установка зависимостей

Зависимости уже установлены:
```bash
python3 -m pip install -r requirements.txt
```

### 2. Настройка окружения

Файл `.env` уже создан с настройками для разработки.

### 3. Запуск MongoDB

#### Вариант A: Docker (Рекомендуется)
```bash
# Запустить MongoDB через Docker
docker run -d \
  --name mongodb \
  -p 27017:27017 \
  -e MONGO_INITDB_DATABASE=rd \
  mongo:latest

# Проверить что работает
docker ps | grep mongodb
```

#### Вариант B: Локально (если установлен)
```bash
# MacOS
brew services start mongodb-community

# Linux
sudo systemctl start mongod

# Проверить статус
mongo --eval "db.version()"
```

### 4. Запуск приложения

```bash
python3 -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

#### Опции запуска:
- `--reload` - автоперезагрузка при изменении кода (для разработки)
- `--port 8000` - порт сервера
- `--host 0.0.0.0` - доступ со всех интерфейсов

### 5. Проверка работы

После запуска откройте в браузере:

- **Главная страница:** http://localhost:8000
- **API документация:** http://localhost:8000/docs
- **Health check:** http://localhost:8000/health

## Доступные эндпоинты

### Аутентификация
- `POST /api/auth/register` - Регистрация нового пользователя
- `POST /api/auth/login` - Вход в систему
- `POST /api/auth/logout` - Выход
- `GET /api/auth/me` - Информация о текущем пользователе
- `POST /api/auth/password-reset/request` - Запрос сброса пароля
- `POST /api/auth/password-reset/confirm` - Подтверждение сброса пароля

### Игра
- `GET /play` - Главная страница игры
- `GET /api/game/stats` - Статистика игрока
- `GET /api/game/leaderboard` - Таблица лидеров
- `WS /ws` - WebSocket для реального времени

### Инвентарь
- `GET /api/inventory/inventory` - Просмотр инвентаря
- `POST /api/inventory/move-item` - Переместить предмет
- `POST /api/inventory/use-item` - Использовать предмет
- `POST /api/inventory/drop-item` - Выбросить предмет

### Профиль
- `GET /api/profile/{username}` - Информация о пользователе
- `GET /api/profile/car/{username}` - Информация о машине

### Администрирование
- `GET /api/admin/stats` - Статистика сервера
- `POST /api/admin/user/ban` - Забанить пользователя
- `POST /api/admin/user/unban` - Разбанить пользователя
- `POST /api/admin/server/shutdown` - Выключить сервер (требует admin)

## Решение проблем

### MongoDB не подключается

**Проблема:** `pymongo.errors.OperationFailure: command listIndexes requires authentication`

**Решение:**

1. **Если MongoDB требует аутентификацию:**
   ```bash
   # Обновите MONGODB_URL в .env
   MONGODB_URL=mongodb://username:password@localhost:27017/rd?authSource=admin
   ```

2. **Если MongoDB не запущен:**
   ```bash
   # Проверьте статус
   ps aux | grep mongod

   # Запустите
   docker run -d --name mongodb -p 27017:27017 mongo:latest
   ```

3. **Если MongoDB на другом хосте:**
   ```bash
   # Измените MONGODB_URL в .env
   MONGODB_URL=mongodb://your-host:27017/rd
   ```

### Redis не подключается

**Проблема:** Rate limiting fallback на in-memory

**Решение (опционально):**
```bash
# Установить Redis
brew install redis

# Запустить
brew services start redis

# Или через Docker
docker run -d --name redis -p 6379:6379 redis:alpine
```

### Порт уже занят

**Проблема:** `Address already in use: 0.0.0.0:8000`

**Решение:**
```bash
# Найти процесс
lsof -ti:8000

# Убить процесс
kill -9 $(lsof -ti:8000)

# Или использовать другой порт
python3 -m uvicorn app.main:app --port 8001
```

## Production Deployment

Для production используйте:

```bash
# 1. Установить переменные окружения
export ENVIRONMENT=production
export SECRET_KEY=$(openssl rand -hex 32)
export MONGODB_URL=mongodb://user:pass@host:27017/rd?authSource=admin
export REDIS_URL=redis://your-redis-host:6379/0

# 2. Запустить с Gunicorn + Uvicorn workers
gunicorn app.main:app \
  --workers 4 \
  --worker-class uvicorn.workers.UvicornWorker \
  --bind 0.0.0.0:8000 \
  --log-level info
```

### Docker Compose

Для полного стека с MongoDB и Redis:
```bash
docker-compose up -d
```

См. `docker-compose.yml` для конфигурации.
